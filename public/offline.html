STATUS: SERVER / KONEKSI OFFLINE

Server Sedang Tidak Terhubung

Aplikasi SIAP tidak dapat menjangkau server sekolah atau koneksi internet pada perangkat Anda sedang terputus.

Penjelasan & Kemungkinan Penyebab:
  • Server Lokal Sekolah: Aplikasi ini dijalankan dari server on-premise sekolah. Jika terjadi pemadaman listrik atau kendala jaringan internet di sekolah, server untuk sementara waktu tidak dapat diakses secara online.
  • Koneksi Pengguna: Periksa kembali jaringan WiFi atau paket data seluler pada perangkat Anda.
  • Keamanan Data: Jangan khawatir, seluruh data presensi, jurnal, dan nilai yang telah tersimpan sebelumnya tetap aman di server sekolah.
  • Absen Susulan: Apabila terkendala pemadaman listrik hari ini, presensi GTK dapat disusulkan oleh Admin / Waka setelah listrik dan server kembali online.
